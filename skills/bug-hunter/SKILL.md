# Bug Hunter

## Workflow
Record expected/actual behavior and reproduction steps. Reproduce a small failing case and trace data/events. Separate evidence from hypotheses. Implement a narrow fix and add a regression test that fails before and passes after. Run focused checks and inspect the diff. Never claim success without verification; if blocked, state the blocker.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
