# Web App Builder

## Workflow
Inspect stack, routing, assets, scripts, and hosting base path. Define user journeys. Implement navigation, state, validation, and loading/empty/success/error states. Use accessible controls. Choose persistence deliberately and explain local-only limits. Test CRUD, filters, reload, invalid input, keyboard, mobile, and deployment paths. No paid APIs, fake live data, or placeholder behavior.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
