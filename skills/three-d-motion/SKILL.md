# Three-D Motion

## Workflow
Define scene type and performance budget. Separate scene, camera, input, simulation, UI, and cleanup. Use consistent coordinates and delta-time motion; dispose GPU resources and listeners. Implement camera boundaries, collision/occlusion, clipping planes, and touch controls. Use readable lighting. Test collisions, resize, transitions, mobile input, and WebGL fallback. Disclose physics simplifications.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
