# Pixel Forge

## Workflow
Inspect existing styles and framework; define visual hierarchy, typography, spacing, surfaces, and restrained colors. Support narrow and wide screens without overflow. Make every visible control work. Include focus, disabled, loading, empty, and error states. Use semantic HTML, keyboard support, labels, contrast, and reduced-motion support. Run available checks and disclose anything not verified.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
