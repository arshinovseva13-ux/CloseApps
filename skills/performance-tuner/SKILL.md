# Performance Tuner

## Workflow
Define a metric: load time, frame time, latency, memory, bundle size, or requests. Establish a reproducible baseline and identify the dominant bottleneck. Make one focused change and re-measure the same metric. Test correctness afterward. Never invent measurements or present speculation as a measured gain; document trade-offs.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
