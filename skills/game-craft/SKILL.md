# Game Craft

## Workflow
Define core loop, controls, win/lose conditions, and restart. Separate rendering, simulation, input, collision, and UI. Use delta time and clamp large frame gaps. Test collision edges and tunneling. Support keyboard and touch controls. Verify state transitions and complete reset. Do not call a game playable until the core loop is exercised.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
