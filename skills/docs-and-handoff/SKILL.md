# Docs and Handoff

## Workflow
Inspect repository facts and verify commands, paths, scripts, environment names, and deployment. Document setup, run/build/test, configuration, usage, and troubleshooting. Never invent commands or include secrets. Audit required features, dead buttons, links, placeholders, errors, responsive layout, keyboard focus, and empty/error states. Report actual checks and publication status. Every score below 10/10 needs concrete drawbacks; unknowns are NOT VERIFIED.

## Final report
Summarize decisions, changed files, checks actually run, results, and limitations. Separate verified facts from assumptions.
