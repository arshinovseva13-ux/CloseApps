Как установить

Архивы формируются прямо в браузере — сторонние сервисы не нужны.

01 · Claude.ai

Открой Customize → Skills → добавление навыка → Upload a skill. Загрузи ZIP конкретного навыка: внутри находится папка с SKILL.md. Затем включи навык. Может потребоваться включить выполнение кода и создание файлов.

02 · Claude Code

Скачай архив Claude Code и распакуй папки в ~/.claude/skills/ или .claude/skills/ внутри проекта.

03 · Проверка

У каждого навыка есть TESTS.md. Общие сценарии доступны в приёмочных тестах, валидатор — в Python-файле.

04 · Безопасность

Skills — инструкции, а не новые права доступа. Они не обходят ограничения среды. Нельзя заявлять, что тесты или публикация прошли успешно, если это не проверено.

Независимый проект Close Приложения. DevCraft не является официальным продуктом Anthropic. Перед включением Skills проверяй инструкции. Платные API и ключи не требуются.
