# DevCraft — Claude Skills Library v1.0

Ten modular Skills for full-cycle software development. Each skill directory contains an Anthropic-compatible `SKILL.md` with YAML frontmatter and a `TESTS.md` checklist.

## Claude.ai
Open Customize → Skills → Add/upload skill. Download one individual ZIP from the Skills page; each archive contains the skill folder at its root. Code execution and file creation may need to be enabled; availability depends on account settings.

## Claude Code
Download the Claude Code ZIP and extract skill folders into `~/.claude/skills/` or `.claude/skills/` inside a project. No paid APIs or API keys are required. Review instructions before enabling them; skills do not replace permissions, tests, or security review.
