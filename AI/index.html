02 · Training Lab

2 запуска

Экспериментальные модели обучены на CPU; результаты и веса сохранены в Deepnote.

  • Run 001: byte-level Transformer, 842 496 параметров, 120 шагов; validation loss — 2.3902
  • Run 002: character-level Transformer, 874 496 параметров, 300 шагов; validation loss — 3.6311
  • Run 002 обработал выборку 8 515 записей и 700 000 символов
  • Генерация уже работает технически, но текст пока бессвязный
  • Это proof-of-training, а не готовая LLM; значения loss двух разных токенизаторов напрямую не сравниваются
