CLAUSE-OPT

Гибридный оптимизатор для экспериментов с Clause Astra. Он сочетает матричный путь обновления параметров на основе momentum и Newton–Schulz с адаптивным AdamW-подобным путём для остальных параметров.

V1.0.0 · API зафиксирован

Первый стабильный релиз интерфейса

CLAUSE-OPT 1.0.0 фиксирует начальный публичный API Python-пакета, правила маршрутизации параметров, формат настроек и проверяемое поведение. Это исследовательский оптимизатор: номер V1 означает стабилизацию интерфейса, а не доказанное превосходство над AdamW или Muon.

01 · Matrix path

Muon-inspired

Для двумерных матриц: momentum, опциональный Nesterov и итерации Newton–Schulz для приближения ортогонализованного обновления.

  • FP32 расчёты и состояние оптимизатора
  • Настраиваемое число итераций
  • Отдельный масштаб learning rate

02 · Adaptive path

AdamW-style

Для векторов, эмбеддингов, нормализаций, bias и выбранных групп параметров.

  • Первый и второй моменты
  • Bias correction
  • Decoupled weight decay

03 · Safety checks

Regression tests

Проверки параметров конфигурации и поведения оптимизатора на некорректных входах.

  • Невалидные гиперпараметры отклоняются
  • Sparse gradients явно не поддерживаются
  • Проверяются state_dict и closure
  • Опциональный trust cap ограничивает относительный шаг

04 · Benchmark

AdamW / Muon

В репозитории есть воспроизводимый синтетический benchmark с одинаковыми seeds, данными и моделью.

  • Validation loss и steps/sec
  • CPU и CUDA режимы
  • JSON-отчёт для каждого запуска
  • Результаты не заменяют тест на настоящей LLM

Быстрый пример API

from clause_opt import ClauseOpt

optimizer = ClauseOpt(
    [
        {"params": matrix_parameters, "algorithm": "matrix"},
        {"params": adaptive_parameters, "algorithm": "adaptive"},
    ],
    lr=1e-3,
    weight_decay=0.01,
)

Полная документация, установка, параметры и команды тестирования находятся в CLAUSE-OPT.md внутри репозитория разработки.

Что V1 пока не обещает

Пока не завершено сравнение на GPU T4 и обучение реальной языковой модели с одинаковым токен-бюджетом. Синтетический тест не доказывает, что CLAUSE-OPT обучает Clause Astra лучше AdamW или Muon. Trust cap и автоматическая маршрутизация параметров остаются эвристиками, которые предстоит проверять отдельными экспериментами.
