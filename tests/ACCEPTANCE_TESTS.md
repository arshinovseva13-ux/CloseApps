# DevCraft acceptance tests

Run the corresponding prompt with each Skill enabled. Record invocation, evidence, and unverified checks.

## Pixel Forge
Create a responsive space-observatory landing page; test mobile/desktop, keyboard focus, contrast, and working links.

## Code Architect
Inspect a repo and plan a minimal feature without breaking existing behavior.

## Bug Hunter
Reproduce a stale-save bug and add a regression test that fails before the fix.

## Game Craft
Build a platformer with acceleration, jump, solid platforms, hazards, restart, and touch controls.

## Test Engineer
Create acceptance criteria and a risk-based matrix for CRUD, filters, persistence, invalid input, and empty states.

## Performance Tuner
Diagnose a sluggish 5,000-item list, measure a baseline, and compare the same metric after optimization.

## Secure Builder
Review form/API code for injection, authorization gaps, secrets, and unsafe uploads.

## Docs and Handoff
Write a README from verified facts and audit dead buttons, links, paths, and test status.

## Web App Builder
Build a task tracker with create/edit/complete/filter and local persistence; test reload and mobile.

## Three-D Motion
Build a 3D scene with camera controls, collision boundaries, lighting, and transitions; test camera clipping.

## Cross-skill rules
- Never claim unrun checks passed.
- Do not invent measurements or deployment status.
- Mark unavailable checks NOT VERIFIED.
- Any quality score below 10/10 must explain concrete drawbacks.
