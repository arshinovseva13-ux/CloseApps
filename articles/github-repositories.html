📁 Репозитории GitHub: создание, структура и настройки

Как создать репозиторий, выбрать видимость и организовать файлы проекта.

Статья №35 · Серия «GitHub: от новичка до разработчика» · 16 ноября 2026

Репозиторий (repository) — основное пространство проекта на GitHub. В нём хранятся файлы, каталоги и история изменений. Репозитории подходят для сайтов, приложений, библиотек, документации и наборов данных.

Создание

  1. Нажмите New repository.
  2. Укажите понятное имя латиницей, например my-first-site.
  3. Добавьте короткое описание.
  4. Выберите Public или Private.
  5. При необходимости добавьте README и лицензию.
  6. Нажмите Create repository.

Видимость

ТипДоступТипичный сценарий
PublicВсемПортфолио, Open Source, публичный сайт.
PrivateВладельцу и приглашённымЗакрытая разработка.

Пример структуры сайта

my-site/\n├── index.html\n├── README.md\n├── assets/\n│   ├── images/\n│   └── icons/\n├── css/style.css\n└── js/app.js

Это пример, а не обязательный стандарт. Структура зависит от проекта. Не создавайте пустые каталоги «на всякий случай».

Полезные файлы

  • README.md — описание и инструкция.
  • LICENSE — условия использования кода.
  • .gitignore — файлы, которые Git не должен отслеживать.
  • CONTRIBUTING.md — правила участия.
  • SECURITY.md — порядок сообщения об уязвимостях.

Настройки

В Settings управляют доступом, ветками, Pages, Actions и защитой репозитория. Набор доступных функций зависит от типа аккаунта и настроек проекта.

Начинайте с простой структуры, которую легко понять новому участнику. Перед открытием репозитория проверьте содержимое и историю на секреты.
