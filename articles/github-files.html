📄 Файлы на GitHub: загрузка, редактирование и организация

Как добавлять и изменять файлы через веб-интерфейс и мобильное приложение.

Статья №37 · Серия «GitHub: от новичка до разработчика» · 16 ноября 2026

GitHub позволяет добавлять и редактировать файлы прямо в браузере. Это удобно для документации, небольших исправлений и простых проектов. Для масштабных изменений лучше использовать локальный редактор и Git.

Создание файла

  1. Откройте репозиторий и нужную папку.
  2. Выберите Add file → Create new file.
  3. Укажите имя, например docs/guide.md.
  4. Добавьте текст и просмотрите результат.
  5. Создайте коммит с ясным сообщением.

Загрузка файлов

Через Add file → Upload files можно выбрать файлы и загрузить их в репозиторий. После загрузки укажите сообщение коммита и сохраните изменения. Для больших объёмов удобнее Git или GitHub Desktop.

Как появляются папки

Git отслеживает файлы, а не пустые каталоги. Поэтому каталог на GitHub появляется, когда в него добавлен файл. Например, путь images/logo.svg создаёт папку images вместе с файлом.

Мобильный сценарий

GitHub Mobile прежде всего предназначен для просмотра, уведомлений и работы с обсуждениями. Набор действий с файлами может быть ограничен. Для серьёзного редактирования на телефоне можно использовать браузер в режиме сайта для компьютера, но удобство зависит от устройства.
