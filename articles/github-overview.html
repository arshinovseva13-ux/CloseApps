🐙 GitHub: что это такое и как устроена платформа

Знакомство с GitHub: Git, репозитории, совместная работа и мобильное приложение.

Статья №34 · Серия «GitHub: от новичка до разработчика» · 16 ноября 2026

GitHub — платформа для размещения Git-репозиториев и совместной работы над проектами. Здесь хранят исходный код, обсуждают задачи, проверяют изменения и автоматизируют сборку и публикацию.

Git и GitHub — разные вещи

ТерминЗначение
GitСистема контроля версий, которая сохраняет историю изменений.
GitHubОнлайн-платформа для Git-репозиториев и командных процессов.
РепозиторийПроект, его файлы и история версий.
КоммитЗафиксированный набор изменений.
ВеткаОтдельная линия разработки.

Что доступно с телефона

GitHub Mobile удобен для уведомлений, просмотра репозиториев, обсуждения Issues и Pull Requests, проверки статусов и быстрых действий. Он не заменяет полноценную среду разработки: для больших правок, сборки и отладки обычно нужен компьютер или облачная среда.

Публичные и приватные проекты

Public-репозиторий доступен всем. Private виден владельцу и приглашённым участникам. Перед публикацией проверьте файлы и историю на пароли, токены, приватные ключи и личные данные.

С чего начать

  1. Создать аккаунт и включить двухфакторную защиту.
  2. Создать тестовый репозиторий с README.
  3. Добавить файл и сохранить коммит.
  4. Создать ветку и предложить изменение через Pull Request.
GitHub — это не просто облачная папка, а рабочая система для хранения, обсуждения, проверки и выпуска проектов.
