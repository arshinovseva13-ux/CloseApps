Схема обучения искусственного интеллекта

Что происходит между загрузкой обучающего пакета и изменением весов нейросети? Разбираем полный цикл: прямой проход, вычисление функции потерь, обратное распространение градиентов и работу оптимизатора AdamW.

1. Полный цикл обучения

Для большинства нейросетей обучение организовано как повторяющийся цикл. Модель получает пакет примеров, строит предсказания, измеряет ошибку, вычисляет градиенты и обновляет параметры. Затем цикл повторяется на следующем пакете.

От данных до новых весов

1Вливка данныхBatch загружается в память и передаётся модели.
2Forward passСеть вычисляет предсказания по текущим параметрам.
3Loss / погрешностьПредсказание сравнивается с целевым ответом.
4BackpropagationВычисляются градиенты функции потерь по параметрам.
5OptimizerОптимизатор рассчитывает величину и направление обновления.
6Обновление весовНовые параметры сохраняются для следующего шага.

Важно не путать три вещи. Loss измеряет ошибку; backpropagation вычисляет, как параметры повлияли на эту ошибку; optimizer использует градиенты, чтобы изменить параметры.

2. Что именно подаётся на вход

В языковой модели исходный текст сначала превращается в токены, затем — в числовые идентификаторы. Из последовательностей формируются обучающие примеры. Для авторегрессионной модели вход и целевые метки обычно сдвинуты на один токен: модель учится предсказывать следующий токен.

Мини-пример формирования пары «вход → цель»

ПозицияВход моделиЦелевой токенЧто проверяем
1«Нейросеть»«обучается»Продолжение после первого токена
2«Нейросеть обучается»«на»Контекст из двух токенов
3«Нейросеть обучается на»«данных»Контекст из трёх токенов

Это учебная иллюстрация принципа next-token prediction, а не реальный токенизатор: в настоящей модели слова могут разбиваться на части.

3. Forward pass: получение предсказания

На прямом проходе данные проходят через слои модели. В Transformer это включает embedding, позиционную информацию, блоки self-attention и feed-forward, а затем выходную проекцию в словарь токенов. На выходе получаются логиты — оценки для возможных следующих токенов. Softmax преобразует их в вероятности.

Упрощённая цепочка вычислений

4. Loss: как измеряется ошибка

Для языковой модели часто используют cross-entropy loss. Если правильный следующий токен получил низкую вероятность, вклад этой позиции в ошибку будет большим. Если вероятность правильного токена высока — вклад будет меньше.

L = − (1 / N) · Σᵢ log pθ(yᵢ | xᵢ)

Здесь N — число учитываемых целевых токенов, yᵢ — правильный токен, xᵢ — доступный контекст, а pθ — вероятность, которую назначила модель с параметрами θ.

Почему низкая вероятность означает большую потерю?

Вероятность правильного токена−ln(p)Интерпретация
0,900,105Предсказание близко к цели
0,500,693Модель не уверена
0,102,303Модель сильно ошиблась
0,014,605Очень низкая вероятность цели

Числа рассчитаны по −ln(p), округлены до трёх знаков. Это иллюстрация вклада одной позиции, а не измерение качества конкретной модели.

5. Backpropagation: от ошибки к градиентам

После вычисления loss нужно понять, как каждый параметр влияет на итоговую ошибку. Для этого применяется правило цепочки производных. Градиент показывает локальное направление наиболее быстрого роста функции потерь; чтобы уменьшить loss, оптимизатор обычно делает шаг в противоположном направлении.

Поток вычисления градиента

Схема концептуальная: в реальной вычислительной граф-сети градиенты проходят от выходных операций к параметрам всех участвующих слоёв.

6. Оптимизатор AdamW: что он делает с градиентами

Оптимизатор не ищет «правильный ответ» напрямую. Он использует градиенты, чтобы обновить параметры. AdamW хранит экспоненциальные средние градиентов и их квадратов, корректирует смещение этих оценок на ранних шагах и отдельно применяет weight decay.

Внутренняя схема одного шага AdamW

AГрадиент gₜПолучен из backpropagation.
BПервый момент mₜСглаженное среднее градиентов.
CВторой момент vₜСглаженное среднее квадратов градиентов.
DBias correctionКоррекция смещения оценок в начале обучения.
EAdaptive stepМасштабирование шага по оценкам моментов.
FWeight decay + updateОтдельное затухание весов и обновление θ.

Формулы AdamW

mₜ = β₁ mₜ₋₁ + (1 − β₁) gₜ
vₜ = β₂ vₜ₋₁ + (1 − β₂) gₜ²
m̂ₜ = mₜ / (1 − β₁ᵗ)       v̂ₜ = vₜ / (1 − β₂ᵗ)
θₜ₊₁ = θₜ − η · m̂ₜ / (√v̂ₜ + ε) − ηλθₜ

β₁ и β₂ задают коэффициенты сглаживания; η — learning rate; ε предотвращает деление на ноль; λ — коэффициент weight decay. В последней формуле показана распространённая запись decoupled weight decay для AdamW.

Ключевое различие: обычный L2-регуляризатор добавляет штраф к функции потерь и тем самым влияет на градиент. В AdamW weight decay отделён от адаптивной части обновления — именно это означает decoupled weight decay.

10. Один шаг — ещё не обучение

Один optimizer step обрабатывает один пакет данных. Эпоха — полный проход по обучающей выборке. Большая языковая модель может обучаться на огромном числе пакетов и токенов; при распределённом обучении один логический шаг может включать синхронизацию градиентов между несколькими ускорителями.

На практике перед обновлением часто выполняют обнуление старых градиентов, а при gradient accumulation суммируют градиенты нескольких микропакетов. При смешанной точности применяют специальные меры для численной стабильности.

11. Итоговая карта процесса

12. Вывод

Обучение нейросети — это не абстрактное «впитывание информации», а конкретный вычислительный процесс. Данные проходят через модель; функция потерь измеряет расхождение с целями; backpropagation вычисляет градиенты; оптимизатор на их основе меняет параметры. Качество обучения оценивают на отдельных данных и по динамике метрик.

Короткая формула всего цикла: данные → предсказание → loss → градиенты → optimizer → новые веса → повторение.
